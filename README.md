# Яблонька — учёт остатков

Приложение (PWA) для продавцов: голосом называешь списание — оно попадает на лист своей точки в Google-таблице.

- Страница и иконки — здесь, на GitHub Pages.
- Распознавание (Gemini) и запись в таблицы — в Google Apps Script (`API_URL` в `index.html`).

Установка на Android: открыть сайт в Chrome → «Установить приложение» (или ⋮ → «Установить приложение»).
